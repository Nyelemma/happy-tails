# Happy Tails Assets

Drop your brand assets here. Placeholder images are already in place so the site looks complete while you prepare your own photos.

## Expected files

| Path | Purpose |
|------|---------|
| `logo.svg` or `logo.png` | Primary logo (nav + footer) |
| `hero.webp` | Large hero image |
| `about.webp` | About section photo |
| `gallery/01.webp` … | Gallery images |

Prefer WebP for photos. If you add new gallery images, update `src/data/content.ts`.
