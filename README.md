# Happy Tails

Premium website for Happy Tails — professional pet sitting and boarding in Southport.

## Stack

- React + TypeScript (Vite)
- Tailwind CSS
- Framer Motion

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Easy updates

| What | Where |
|------|--------|
| Phone, WhatsApp, email, hours | `src/lib/site.ts` |
| Services, FAQs, testimonials, gallery | `src/data/content.ts` |
| Images & logo | `public/assets/` |

Replace the placeholder images in `public/assets/` with your own Happy Tails photos and logo. Keep the same filenames, or update the paths in `src/data/content.ts`.
